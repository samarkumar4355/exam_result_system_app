- User.countDocuments({ role: "student" }) — sirf student accounts count karta hai, admin accounts nahi.

- Exam.countDocuments() — database mein total exams count karta hai.

- Result.countDocuments() — saved result records count karta hai.

- try-catch — database query fail hone par error response deta hai.

- module.exports — controller ko route file mein import karne deta hai.
